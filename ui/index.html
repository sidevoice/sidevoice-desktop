Ajustes

Con qué máquina hablas lo decide el emparejamiento: pide a tu agente «empareja un dispositivo» (o ejecuta sidevoice pair-device en la máquina) y pega el código en la ventana de Sidevoice → Máquinas. El código ya dice cómo llegar a la máquina.

Un nodo (el núcleo de una máquina) o una sala de encuentro. Vacío está bien: el código de emparejamiento lleva sus direcciones. https://, o http:// solo en este ordenador.

Funciona aunque Sidevoice esté en segundo plano. Vacío lo desactiva. Formato: CmdOrCtrl+Shift+M, Alt+F9…
